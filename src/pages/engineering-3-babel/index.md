Babel 是一个 JavaScript 编译器，将 ES205+ 的代码转换成向后兼容的版本。Babel 主要做以下几个事情：

- 转换 JS 语法
- 补充目标环境缺少的 Polyfill（利用第三方库，比如 core-js）
- 源代码转换

## 核心概念

### Plugins

转换代码的插件，指导 Babel 如何对代码进行转换。

### Presets

Preset 是一组已经包含了各种插件的集合，代替一个一个手动引入插件。

## 原理

将 JS 代码转换为 AST，对 AST 应用各种插件进行处理，最终输出编译后的 JS 代码。

### 流程

1. 解析

  将代码转换成 AST

2. 转换

  对 AST 进行**深度优先遍历**，对节点进行添加、更新以及移除等操作。这个阶段是插件将要介入的地方。

3. 生成

  将上一阶段处理后的 AST 转换为代码
